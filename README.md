# Sistema de cadastro e bonificação de novos colaboradores

## descrição

Sistema resposavel pelo cadastro de novos colaboradores. No sistema, devera ser informado o nome do colaborador e seu respectivo salário. o sistema deverá retornar uma mensagem de boas vindas dizendo ao colaborador o seu salario base juntamento com o seu salario bonificado com 15%.

# Funcionalidade

## Descrição

Iremos colocar um sistema de cadastro para os Novos Talentos entrarem. A gente irá colocar um codigo python para conseguirem cadastrar e entrar na conta. quando cadastrarem irão se deparar com o seu salario e o seu salario bonificado(15%).

# Como os usuários podem utilizá-lo

## Descrição

os usuários irão ultilizar para ver o seu salario atual e se teve alguma alteração ou bônus.
